# ГИС Екатеринбург — карта и онлайн-админка

PHP-версия для Linux использует PHP 8.3+, SQLite и готовый браузерный обработчик импорта. Команды выполняются из корня проекта.

```bash
./start.sh
```

На локальной машине карта открывается по `http://127.0.0.1:3000/`, админка — по `http://127.0.0.1:3000/admin/`. Первый запуск подготовит SQLite и создаст `ADMIN_KEY` в `.env`, если ключ отсутствует. Остановить локальный сервер можно через `Ctrl+C`.

Для хостинга запустите `./start.sh --setup-only` и укажите каталог `public/` как корень домена. [Требования PHP, настройки FastCGI и перенос базы](docs/DEPLOYMENT.md).

## Данные и публикация

Исходный реестр содержит **2 569 записей** и **2 571 контур**. Карта читает последнюю опубликованную версию из SQLite. После редактирования в `/admin/` нажмите «Опубликовать». Рабочая база, загрузки и резервные копии хранятся в `server/gis-ekb.sqlite`, `data/uploads/` и `data/backups/`. [Руководство по админке](docs/ADMIN.md).

## Разработка обработчика импорта

Браузерный обработчик включён в репозиторий. Node.js используется разработчиком для обновления этого файла и для тестов общего кода импорта.

```bash
npm ci
npm run build:import-worker
npm test
```
