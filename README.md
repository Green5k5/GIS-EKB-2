# ГИС Екатеринбург — карта и админка

Дважды нажмите **start.cmd**. Он подготовит компоненты и откроет две страницы:

- Карта: **http://127.0.0.1:8090/**.
- Админка: **http://127.0.0.1:8090/admin/**.

Ключ админки берётся из `ADMIN_KEY` в локальном `.env`. Если он не задан, создаётся автоматически. Для входа скопируйте ключ из **`.runtime/admin-key.txt`**. Пример настроек — `.env.example`.

Для первого запуска может потребоваться интернет, чтобы скачать Node.js и зависимости. Повторное нажатие открывает уже работающие страницы. Окно запуска после завершения можно закрыть. **stop.cmd** останавливает сервер.

Подходящий установленный Node.js используется автоматически. Если его нет, скачивается переносимая версия. Зависимости устанавливаются по `package-lock.json`. Обычный запуск работает без XAMPP, Docker, PHP и модели.

Для `start.cmd` понадобится Windows 10/11 x64. ИИ-помощник временно отключён. [Материалы для разработки помощника](ai/README.md).

## Данные

В комплект входят **2 569 записей, 2 571 контур, три поселения, 21 исторический план, 56 объектов исторических слоёв и словарь**. Исходные файлы находятся в `js/data-records.js`, `js/data-polygons.js`, `js/map.js`, `js/layers.js`, файлах глоссария и `assets/`. Сохранены более поздние исправления данных и интерфейса из main.

Первый запуск переносит исходный набор в пустую SQLite-базу и создаёт первую публикацию. Повторный запуск сохраняет коллекцию и ручные правки. Намеренно очищенная карта с историей публикаций остаётся пустой.

Карта читает опубликованный снимок `/api/public/bootstrap`. После правок в админке нажмите «Опубликовать», чтобы обновить данные посетителей. Усадьбы, планы, исторические улицы, реки и крепость отображаются в мастерской. [Руководство админки](docs/ADMIN.md).

Рабочая база — `server/gis-ekb.sqlite` (можно переопределить через `DB_PATH`), изображения — `data/uploads/`, резервные копии — `data/backups/`. Сохраняйте их вместе при переносе отредактированной коллекции. Они, `.env`, зависимости, модель и `.runtime/` исключены общим `.gitignore`. Исходный набор первого запуска остаётся в Git.

## Проверка и диагностика

`start.cmd` запускает карту и админку на `127.0.0.1:8090`. Журналы находятся в `.runtime/backend.*.log`.

Запуск без браузера:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start-local.ps1 -NoBrowser
```

Проверки (для разработки установите все зависимости через `npm ci`):

```powershell
npm test
node tools/test-map-camera.cjs
node tools/test-scan-viewer.cjs
node tools/test-street-selection.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-local-launcher.ps1
```

Из корня проекта можно запустить `npm run migrate`, чтобы подготовить SQLite-базу, а затем `npm start`, чтобы открыть карту и админку на порту 3000. [Размещение на сервере](docs/DEPLOYMENT.md).
