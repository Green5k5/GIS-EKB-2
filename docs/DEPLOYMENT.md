# Развёртывание GIS-EKB на PHP и SQLite

Ветка `php-sqlite-deploy` рассчитана на PHP 8.3 или новее. Нужны расширения `pdo_sqlite`, `session`, `zip`, `zlib`, `mbstring` и `gd` с WebP. Карта и онлайн-админка работают через PHP FastCGI. Браузер запускает готовый обработчик импорта. На хостинге достаточно PHP и SQLite.

Резервное копирование использует `VACUUM INTO` на SQLite 3.27 и новее. На SQLite 3.24–3.26 приложение копирует схему и данные в отдельный файл через то же соединение PDO и в одной транзакции. Версия SQLite определяется через соединение приложения, которое выполняет операцию.

## Подготовка по SSH

1. Загрузите ветку `php-sqlite-deploy` в каталог проекта и перейдите в него. Оригиналы загрузок и резервные копии храните вне каталога, который веб-сервер отдаёт посетителям.
2. Для переноса существующего сайта сделайте согласованную SQLite-копию рабочей базы. Остановите запись на время копирования или используйте команду SQLite `.backup`. Положите копию в `server/gis-ekb.sqlite` и перенесите `data/uploads/`. При необходимости перенесите и `data/backups/`. Для нового сайта оставьте эти каталоги пустыми.
3. Создайте `.env` по образцу `.env.example`. Задайте `APP_ENV=production` и сохраните текущий `ADMIN_KEY` или оставьте его пустым для генерации. Пути `DB_PATH` и `GIS_DATA_DIR` можно указать отдельно. Учётной записи PHP нужны права на запись в каталог базы и каталоги данных.
4. Выполните из корня проекта:

   ```bash
   php --version
   ./start.sh --setup-only
   ```

   Если в SSH команда `php` запускает другую версию, передайте путь к PHP CLI своего хостинга через `PHP_BIN`, например `PHP_BIN=/path/to/php83 ./start.sh --setup-only`. Подготовка добавит недостающие поля старой базе, а для новой загрузит исходные данные. Повторный запуск сохраняет записи и публикации.

## Настройка сайта в ispmanager

1. В параметрах сайта задайте **корневой каталог `public/` внутри проекта**. В нём лежат `index.php` и `.htaccess`. Если загружали по FTP, убедитесь, что передался скрытый файл `.htaccess`.
2. Выберите **PHP FastCGI (Apache) 8.3+** для домена. Для маршрутов `/admin/` и `/api/...` нужен Apache с разрешённым `mod_rewrite` для `.htaccess`. Скрипт подготовки проверяет модули CLI. Попросите хостера проверить тот же набор расширений для домена, если CLI и FastCGI используют разные настройки.
3. Включите HTTPS. Откройте главную страницу и `/admin/`. Для входа используйте `ADMIN_KEY` из `.env` или из окружения PHP.
4. Проверьте, что `/api/health` возвращает `"ok":true`, а `/.env`, `/.git/HEAD` и `/server/gis-ekb.sqlite` возвращают 404. Проверьте вход, сохранение черновика и публикацию на тестовой копии.

## Импорт на виртуальном хостинге

Загрузки CSV, XLS/XLSX, ZIP, SHP/DBF/PRJ, QGZ и GeoTIFF остаются в онлайн-админке. ZIP распаковывается на сервере, исходные файлы доступны только по запросу авторизованной админки, а таблицы, геопривязка и превью разбираются в браузере. Для анализа оставьте вкладку открытой. После перезагрузки страницы сохранённый набор можно проанализировать повторно.

Ограничения на размер HTTP-запроса, время распаковки, память и дисковую квоту зависят от тарифа. Если хостинг отклоняет большой ZIP, загрузите файлы отдельно или разделите набор по поселениям. Для больших GeoTIFF полезны внутренние пирамиды разрешений или меньший исходный растр с той же геопривязкой. Проверяйте такие наборы до смены действующего сайта.

Если админка просит проверить журнал сервера, откройте журнал ошибок домена в ispmanager через «Настройки веб-сервера» → «Журналы WWW». Типовой путь — `/var/www/httpd-logs/ИМЯ-ДОМЕНА.error.log`. Ищите запись с префиксом `gis-ekb:` за время ошибки. Если у PHP задан отдельный `error_log`, запись будет в указанном там файле.

## Локальная проверка и обновления

```bash
./start.sh
# В другой консоли
curl -fsS http://127.0.0.1:3000/api/health
```

Для локального запуска используется встроенный сервер PHP, который останавливается по `Ctrl+C`. На рабочем хостинге отвечает FastCGI. При обновлении сначала сохраните копии базы и `data/uploads/`, подтяните ветку и снова выполните `./start.sh --setup-only`.
