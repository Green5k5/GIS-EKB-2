# Размещение сайта и ветки

## main — сайт для обычного хостинга

Ветка `main` содержит карту, фильтры, таблицу и инфографику. Выбор усадеб по клику на историческую улицу, плашка выбранной улицы, стабильный масштаб и отступы карточек работают в браузере. Формы вопросов к ИИ, обращений к `ai/` и файлов моделей в этой версии нет.

Для обновления возьмите файлы из `main`. Загрузите `index.html`, `css/`, `js/`, `assets/` и `vendor/` в корень сайта, сохраняя структуру каталогов. Если хостинг получает сайт через Git, обновите именно `main` обычным fast-forward. Root-доступ, PHP и llama.cpp для этой версии не требуются.

Перед заменой сохраните резервную копию действующего сайта. После загрузки проверьте карту, выбор поселения, клик по улице и очистку её фильтра. Обновлённые CSS/JS подключены с новыми параметрами версии для сброса кеша браузера.

Не загружайте `.git/`, `tools/`, `docs/`, `ai/` и `models/` в публичный каталог сайта.

## AI — полная версия с помощником

Ветка `AI` сохраняет вопросы к базе, гибридный разбор, интерактивные ответы и отмену запроса. Для её серверной части нужны PHP и отдельный локальный процесс llama.cpp; порядок запуска описан в `ai/README.md` этой ветки.

GGUF-модели, установленный Windows-движок и журналы не хранятся в опубликованных ветках Git. Локальные файлы модели и движка сохранены на рабочей машине. Их исходная локальная история сохранена в резервной ветке `codex/ai-local-backup-20261013`; эту ветку не нужно отправлять на GitHub.
