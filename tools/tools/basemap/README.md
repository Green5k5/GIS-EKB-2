# Карта «ГИС Екатеринбург»: собственная подложка и движок «Картограф»

С сентября 2026 года сайт не зависит ни от CARTO, ни от Leaflet. Подложка
собирается из данных OpenStreetMap и лежит на нашем же сервере, а карту
рисует собственный движок «Картограф» (`js/kartograf/`).

## Как это устроено

| Файл | Что делает |
|---|---|
| `assets/basemap/basemap.json` | Описание подложки: границы, зумы, атрибуция, индекс существующих тайлов, все точечные подписи (районы, посёлки, водоёмы, станции) |
| `assets/basemap/offline/` | Те же тайлы, упакованные в скрипты, — для просмотра без сервера |
| `assets/basemap/tiles/{z}/{x}/{y}.pbf` | Векторные тайлы в стандартном формате Mapbox Vector Tile, зумы 10–15 |
| `js/kartograf/mvt.js` | Декодер векторных тайлов, без зависимостей |
| `js/kartograf/render.js` | Стиль подложки (светлая и тёмная палитры) и отрисовка одного тайла |
| `js/kartograf/tile-worker.js` | Фоновый поток: загружает, декодирует и рисует тайлы, отдаёт готовые картинки |
| `js/kartograf/map.js` | Сама карта: вид, жесты, анимации, попап, кнопки масштаба, масштабная линейка |
| `js/kartograf/basemap.js` | Кэш тайлов, подмена недогруженных тайлов соседними уровнями, подписи без наложений |
| `js/kartograf/layers.js` | Слои поверх подложки: исторические планы, крепость/улицы/реки, усадьбы |
| `js/map.js`, `js/layers.js` | Код сайта, который использует движок |

Порядок отрисовки: подложка → подписи подложки → исторические планы →
крепость, улицы, реки 1809 г. → усадьбы → выбранная усадьба →
подписи улиц и рек 1809 г.

С 16-го зума и выше данные берутся из тайлов 15-го зума и масштабируются:
точности хватает до 19-го зума, а файлов в четыре раза меньше.

## Просмотр без сервера

`index.html` можно просто открыть двойным щелчком. Браузер в этом режиме
(`file://`) запрещает загружать файлы тайлов, поэтому движок сам берёт
тайлы из автономного комплекта `assets/basemap/offline/` — те же тайлы,
упакованные в скрипты. Карта при этом рисуется в основном потоке
браузера: первые секунды после перемещения чуть медленнее, чем на сервере,
в остальном всё то же.

После пересборки подложки комплект нужно обновить:

```
python3 tools/basemap/make_offline.py assets/basemap
```

На боевом сервере папка `offline/` не используется (17 МБ), её можно
не выкладывать — сайт от этого не сломается.

### Один файл для просмотра

Проще всего — однофайловая сборка: всё (стили, скрипты, данные, подложка,
исторические планы) в одном `ГИС-Екатеринбург.html`, около 21 МБ. Его
можно скачать и открыть двойным щелчком, ничего не распаковывая:

```
python3 tools/build_single.py
```

Картинки планов в нём пережаты (1500 px по длинной стороне), поэтому
при сильном приближении они чуть мягче, чем на сайте. На хостинг этот
файл выкладывать не нужно.

## Требования к хостингу

На сервере тайлы грузятся напрямую и рисуются в фоновом потоке —
это самый быстрый режим.

Желательно включить на сервере сжатие `.pbf` — тайлы сжимаются примерно
вдвое. Для Apache это делает `assets/basemap/.htaccess`, для nginx:

```
types { application/x-protobuf pbf; }
gzip on;
gzip_types application/x-protobuf application/json;
location /assets/basemap/ { expires 30d; }
```

Кэш браузера сбрасывается сам: к адресам тайлов добавляется дата сборки
из `basemap.json`, а к описанию подложки — `BASEMAP_VERSION` в `js/map.js`.
После пересборки подложки поменяйте `BASEMAP_VERSION`.

## Как пересобрать подложку

Нужен Python 3.10+ и `pip install shapely numpy`.

**Путь 1 — из выгрузки OpenStreetMap (рекомендуемый).**

1. Скачайте свежую выгрузку, например с Geofabrik: `ural-fed-district-latest.osm.pbf`
   (раздел Russia → Ural Federal District).
2. Вырежьте Екатеринбург и выгрузите объекты
   (`osmium-tool` ставится через `apt install osmium-tool`):

   ```
   osmium extract -b 60.27,56.67,60.89,56.96 ural-fed-district-latest.osm.pbf -o ekb.osm.pbf
   osmium export ekb.osm.pbf -o ekb.geojsonseq -f geojsonseq
   ```

3. Соберите тайлы и автономный комплект:

   ```
   python3 tools/basemap/build_basemap.py ekb.geojsonseq assets/basemap
   python3 tools/basemap/make_offline.py assets/basemap
   ```

Этот путь написан под стандартный вывод `osmium export`, но в среде, где
делалась подложка, серверы OSM были недоступны, и проверить его на живой
выгрузке не удалось. При первом запуске сравните результат с текущей картой.

**Путь 2 — из готовых векторных тайлов OSM (так собрана текущая подложка).**

```
python3 tools/basemap/mvt_to_geojsonseq.py <каталог_тайлов> 16 ekb.geojsonseq
python3 tools/basemap/build_basemap.py ekb.geojsonseq assets/basemap
```

Первый скрипт склеивает объекты, разрезанные границами тайлов, и нужен
только для этого пути (`pip install mapbox-vector-tile`). Текущая подложка
собрана из тайлов зума 16 репозитория `ekaterinburgdev/map-tiles`
(данные OpenStreetMap по состоянию на сентябрь 2023 года, обработанные
Apache Baremaps). Файла лицензии
в том репозитории нет; сами данные — OpenStreetMap под лицензией ODbL.

Сборка всего города занимает около минуты на одном ядре.

## Что поменять, если нужно

- **Цвета подложки** — палитры `LIGHT` и `DARK` в `js/kartograf/render.js`.
- **Толщина дорог по зумам** — `ROAD_W` там же.
- **Оформление крепости, улиц и рек 1809 г.** — объект `STYLE` в
  `js/layers.js`: ширины (`spec`: на местности в метрах и минимальная
  толщина в пикселях по зумам, `byName` — ширина отдельных рек), цвета
  для светлой и тёмной темы (`palettes`), приёмы рисования (`look`:
  край ленты, штриховка стены). Там же `SMOOTH_M` — радиусы скругления
  изломов и `POND_DAM_LAT` — участок Исети под прудом рисуется пунктиром.
  Сами приёмы рисования — класс `HistoricLayer` в `js/kartograf/layers.js`.
- **Что из современной подложки скрыто** — железная дорога, трамвай и
  аэродром: `HIDE` в `js/kartograf/render.js`; станции метро и ж/д,
  названия ЖК, кварталов и урочищ: `HIDE_LABEL` в `js/kartograf/basemap.js`.
- **Какие объекты попадают в подложку и с какого зума** — таблицы `*_MINZ`
  и функция `classify()` в `build_basemap.py`.
- **Шрифты подписей** — метод `_font()` в `js/kartograf/basemap.js`.
- **Пределы перемещения карты** — `MAP_MAX_BOUNDS` в `js/map.js`.

## Отладка

- Подробное объяснение устройства — `docs/КАК_УСТРОЕНА_КАРТА.md`.
- `?kg=main` в адресе страницы — рисовать тайлы в основном потоке,
  без фонового (так же движок сам работает в браузерах без OffscreenCanvas).
- В консоли браузера доступны `map` (карта) и `estateLayer` (слой усадеб):
  например, `map.setView([56.8385, 60.6035], 16)`.
