Проверка сканов ведомостей

Страница проходит по всем усадьбам из js/data-records.js и проверяет, что ссылка на скан открывается и ведёт на файл с тем же номером, что у усадьбы. Для ссылок Яндекс Диска используется его публичный API, для файлов на сайте - загрузка картинки. Проверка идёт из вашего браузера; при ограничении частоты запросов (ответ 429) страница сама делает паузу и продолжает.
