# Гибридный помощник KH WAY

ИИ-помощник временно отключён в интерфейсе и в штатном запуске проекта. PHP-обработчики доступны для отдельной локальной проверки при `KH_WAY_AI_ENABLED=1` в окружении PHP. Сервер Node.js их не раздаёт.

Вопрос → быстрый разбор → при необходимости один вызов локальной LLM → проверка запроса → точный расчёт PHP → ответ и источники.

Активный обработчик: `ai/search.php` → `ai/hybrid.php`. Прежний диалоговый агент `native-agent.php` сохранён для сравнения, но не обслуживает интерфейс. Старый `query.php` используется только для нормализации слов и словарей; его прежний обработчик ответов не вызывается.

## Что работает

- Количество усадеб, фильтры по полу, поселению, основным сословиям, фамилии, имени и отчеству.
- Списки различных значений и частотность, средняя/медианная/суммарная/минимальная/максимальная площадь.
- Полный список значений поля улицы без прежнего ограничения в 15 строк.
- Несколько условий И, исключения через модель, числовые границы площади. Диапазон «от … до …» включает границы.
- Короткое «А в Уктусе?» после простого вопроса наследует операцию и остальные фильтры, заменяя поселение.
- Источники, условия запроса, маршрут обработки и время расчёта в интерфейсе.

Быстрый путь используется только при полном разборе вопроса. Нераспознанные слова отправляют вопрос модели. LLM возвращает JSON, ограниченный схемой; не считает и не пишет итоговую историческую справку. Сервер сохраняет явно распознанные условия ФИО, поселения, пола, основных сословий и границы площади независимо от ошибок модели. Дополнительные фильтры проверяются на происхождение из вопроса. Неподдержанные или неоднозначные запросы могут требовать уточнения; это не гарантия понимания произвольного русского текста.

При общем запуске источник — опубликованный снимок /api/public/bootstrap, заданный через KH_WAY_BOOTSTRAP_URL. После публикации помощник использует новые данные. Автономные проверки без этой переменной читают исходный js/data-records.js с 2569 записями. Одна запись означает усадьбу, не уникального человека. Одинаковые ФИО не доказывают тождество владельцев. Исторические написания улиц и описания местоположений сохраняются. Площади — саж²; неположительные/неизвестные площади исключаются из статистики и отмечаются отдельно. Таблица и статистика используют полную выборку ответа.

Пока не поддерживаются произвольные объединения ИЛИ, сравнения нескольких выборок и проценты. Сложные продолжения диалога требуют полного вопроса. При выключенной модели быстрые запросы продолжают работать.

## Локальная проверка Windows

`ai/start-model.cmd` готовит и запускает локальную модель отдельно от сайта. Для проверки API запустите из корня проекта `php -S 127.0.0.1:8091` с `KH_WAY_AI_ENABLED=1` в окружении и направьте `KH_WAY_SITE_URL` на `http://127.0.0.1:8091` для live-теста. Убедитесь, что в PHP включены cURL и mbstring. Модель `models/*.gguf` и скачанные компоненты `.runtime/` хранятся локально.

`php ai/test-hybrid.php` проверяет быстрый маршрут, расчёты и сохранение условий. `php ai/test-hybrid.php --live` дополнительно обращается к работающему сайту и модели. Адрес сайта для live-теста можно задать переменной `KH_WAY_SITE_URL`. `php ai/test-agent.php` проверяет общий модуль вычислений. Старый `test-query.php` относится к прежнему поиску.

Модель: Qwen3-4B IQ3_M, файл 1 962 896 320 байт; сервер llama.cpp, только `127.0.0.1:8080`. Четыре CPU-потока, контекст 4096, один слот, без рассуждений в запросе. Установленный GGUF сохраняется, повторная загрузка не нужна. JSON-ответ ограничен 320 токенами; время ожидания модели определяется `ai/config.php` (90 секунд). На CPU модельный маршрут может занимать десятки секунд, особенно после запуска. Время показано в интерфейсе; оно не включает сетевую задержку и чтение реестра перед обработчиком.

## Ubuntu 24.04 LTS

Нужны PHP 8.1+ с cURL/mbstring и CPU-сборка `llama-server` с поддержкой JSON Schema. Запуск: `ai/start-model.sh`; пример службы — `ai/kh-way-ai.service.example`. URL модели переопределяется `KH_WAY_MODEL_URL`.

Для отдельного стенда разработки целевой профиль — 4 vCPU и 8 ГБ ОЗУ. Скорость зависит от конкретного CPU и нагрузки.

Модель и данные остаются локальными. Лицензия Qwen — Apache 2.0; лицензии и контрольная сумма находятся в `models/`.

## Интерактивный ответ и карта

Ответ возвращает точные ID всей выборки. «Выборка на карте» открывает её целиком, заменяя прежние ручные условия, чтобы они не скрывали найденные записи. Затем обычные фильтры карты могут дополнительно сузить эту выборку. Плашка сверху показывает условия вопроса, число объектов на карте, возврат к таблице, обзор всей выборки и снятие фильтра. Снятие плашки сохраняет дополнительные ручные фильтры; общий «Сбросить» снимает всё.

Панель помощника находится во вкладке «Данные», над таблицей усадеб. Ответ передаёт в таблицу полный набор `map.record_ids`, включая результаты за пределами первых 50 элементов `items`. Группы улиц, фамилий и других значений открывают соответствующие строки таблицы. Максимумы и минимумы отмечены звездой; отдельная кнопка оставляет только найденные экстремумы. Нулевой ответ показывает пустую таблицу.

Нажатие на название столбца меняет сортировку. Иконка фильтра открывает компактную немодальную всплывашку у заголовка: для текста — поиск и галочки значений, для чисел — диапазон «от / до». При поиске «Применить» оставляет отмеченные значения среди найденных. Клик снаружи или Escape закрывает всплывашку без применения. Фильтры объединяются по И. «Сбросить фильтры» сохраняет выборку ответа, «Весь реестр» снимает и ограничение ИИ. Новый ответ сбрасывает прежние фильтры таблицы; сам вопрос всегда считается по опубликованному реестру, а не по локальным фильтрам таблицы.

«Столбцы» открывает дополнительные сведения, включая семью, службу, примечания и исходные данные. Таблицу можно развернуть на весь экран; Escape сворачивает её. CSV выгружает все 25 полей и все строки текущей выборки в текущем порядке, независимо от страницы и скрытых столбцов. Формат для Excel: UTF-8 с BOM, разделитель «;», десятичная запятая; текстовые формулы экранируются. Выборку можно открыть на карте и вернуться кнопкой «К таблице».

Исторические линии улиц также интерактивны: нажатие выбирает усадьбы по явным значениям поля street в Екатеринбурге и подсвечивает линию. Сокращённые формы подписи сопоставляются с названиями реестра. При неоднозначности или более существенном различии написания предлагается выбор; при отсутствии соответствия показывается пояснение, прежняя выборка сохраняется. Географическая близость не используется для приписывания усадеб улице. Проверка сопоставлений и обработки нажатия: `node tools/test-street-selection.cjs`.

Камера карты сохраняется при обычной фильтрации (сословие, пол, площадь, поиск), снятии условий и выборе линии улицы. Переход к единственному поселению происходит только при его включении; снятие поселения не перемещает карту. Обзор выборки и приближение конкретного участка выполняются явными кнопками перехода на карту. Проверка поведения камеры: `node tools/test-map-camera.cjs`.

## Отмена вопроса

Во время обработки есть кнопка «Отменить». Escape в поле вопроса также отменяет поиск. Текст сохраняется для исправления, отменённый ответ не попадает в историю, новый вопрос можно отправить сразу. Новый запрос через кнопку примера автоматически отменяет прежний.

PHP получает от модели поток SSE, собирает JSON-план и отслеживает отмену. Случайный 256-битный ID относится только к одному вопросу; отмена передаётся отдельным POST в `ai/cancel.php` и DELETE `/v1/stream?conv_id=...` на loopback llama.cpp. Процесс модели остаётся загруженным. Прерывание уже запущенного вычислительного пакета CPU может занять несколько секунд. Временные статусы ID находятся вне сайта в системном temp; вопросов и данных владельцев в них нет. Отмена перед стартом запроса тоже учитывается.

Для адресной остановки нужна версия llama.cpp с resumable streams и DELETE `/v1/stream` (сборка 11320 закреплена в запускателе). Для PHP нужны два или более обработчика HTTP, чтобы отмена принималась одновременно с запросом: XAMPP/Apache и обычный PHP-FPM подходят. `start.cmd` использует два отдельных PHP-процесса: запросы идут в один, отмена и статус — во второй через Caddy. Одиночный `php -S` не подходит. Тест состояний и разборщика SSE: `php ai/test-request-control.php`.
